# Maintenance Workflows

Use only the workflow triggered by the current task. Each workflow defines its
source checks, durable wiki updates, exclusions, and verification.

* [Code and documentation sync](code-and-doc-sync.md) - implementation, API,
  documentation, example, schema, or agent-entrypoint changes.
* [Record a decision](record-decision.md) - meaningful technical or product
  choices with long-lived consequences.
* [Release-impacting change](release-change.md) - user-visible package behavior,
  API, output, packaging, or release-process changes.
